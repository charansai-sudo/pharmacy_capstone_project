
# PharmaEasy Capstone Project

A reproducible data analytics and decision-support project built using
Python, Pandas, SQLite, Plotly, and Streamlit.

The project analyzes PharmaEasy order data for April–June 2026 and
produces validated metrics, management reporting, human-review controls,
and an interactive dashboard.
